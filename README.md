# Fonceur.github.io

GitHub Pages user site. Hosts the [app-ads.txt](app-ads.txt) file for the Romi apps
(Google Play and Amazon Appstore), fetched by the AdMob and Amazon Publisher Services crawlers
at `https://fonceur.github.io/app-ads.txt`.

The privacy policy lives in the separate [tromi-legal](https://github.com/Fonceur/tromi-legal) project site.
